VOID GATE - a Portal-style power for Dishonored 2                         (по-русски - ниже)
=================================================

A new power for Corvo and Emily: open two linked rifts into the Void on any wall, floor or ceiling, step into one
and come out of the other, keeping your speed and direction.

INSTALL
  1. Close the game.
  2. Run VoidGateSetup.exe. It finds the game folder by itself or asks for it (the folder with Dishonored2.exe).
  3. Choose 1 - Install.
  4. In the game: journal -> Powers -> Void Gate (4 runes). Select it on the power wheel.

  The setup adds Void Gate on top of the mods you already have (Void Installer mods too). If you install or change
  other mods with Void Installer later, run VoidGateSetup.exe again.

PLAY
  Hold the power button to aim, release to open a rift (15 mana). The first rift is the entrance, the second the
  exit; a new rift replaces the oldest. Tap F (interact) to close both. If a rift strands you far below its exit,
  F also takes you back to where you entered.
  Upgrades: Far Rift (2 runes, twice the range), Through the Void (3 runes, guards, bodies and objects pass),
  Crossfire (3 runes, bolts, bullets and Windblast pass).

UNINSTALL
  Run VoidGate_Uninstall.exe in the game folder (or VoidGateSetup.exe -> 2 - Uninstall). The game folder goes back
  exactly to how it was before Void Gate. Saves made with Void Gate still load afterwards; the power is just gone.

GAME VERSION
  Made and tested only on the GOG version 1.77.9.0. Other versions (Steam, other patches) have NOT been tested.
  At every start the mod checks the game's code; if it differs, the mod turns itself off with a message and the
  game runs normally without it. The setup tells you the result of the same check before installing.

KNOWN LIMITATIONS
  - Mission 7 (A Crack in the Slab): Void Gate uses the Timepiece's power-wheel slot (the game has no free slot).
    While you carry the Timepiece, choose the slot once for the Timepiece and again for Void Gate.
  - No view through a rift (the see-through window flickered and cost frame rate, so it is off).
  - A rift can lead outside the playable level; if you fall under the map, tap F to go back.

ВРАТА БЕЗДНЫ - сила в стиле Portal для Dishonored 2
==================================================

Новая сила для Корво и Эмили: два связанных разлома в Бездну на любой стене, полу или потолке. Войдите в один и
выйдите из другого, сохранив скорость и направление.

УСТАНОВКА
  1. Закройте игру.
  2. Запустите VoidGateSetup.exe. Он сам найдёт папку игры или спросит её (папка с Dishonored2.exe).
  3. Выберите 1 - Установить.
  4. В игре: журнал -> Умения -> Врата Бездны (4 руны). Выберите силу на колесе сил.

  Установщик добавляет Врата поверх уже установленных модов (и модов Void Installer). Если позже ставите или
  меняете моды через Void Installer, запустите VoidGateSetup.exe ещё раз.

КАК ИГРАТЬ
  Зажмите кнопку силы, чтобы прицелиться, отпустите, чтобы открыть разлом (15 маны). Первый разлом - вход,
  второй - выход, новый заменяет самый старый. Короткое нажатие F закрывает оба. Если разлом завёл вас далеко вниз
  от выхода, F вернёт вас к месту входа.
  Улучшения: Дальний разлом (2 руны, дальность вдвое больше), Сквозь Бездну (3 руны, проходят стражники, тела,
  предметы), Перекрёстный огонь (3 руны, проходят болты, пули и Порыв ветра).

УДАЛЕНИЕ
  Запустите VoidGate_Uninstall.exe в папке игры (или VoidGateSetup.exe -> 2 - Удалить). Папка игры станет точно
  такой, как до установки Врат. Сохранения с Вратами после этого загружаются, сила из них просто пропадает.

ВЕРСИЯ ИГРЫ
  Мод сделан и проверен только на GOG-версии 1.77.9.0. Другие версии (Steam, другие патчи) НЕ проверялись.
  При каждом запуске мод сверяет код игры; если он отличается, мод выключается с сообщением, а игра работает как
  обычно, без него. Установщик сообщает результат той же проверки перед установкой.

ИЗВЕСТНЫЕ ОГРАНИЧЕНИЯ
  - Миссия 7 (особняк Стилтона): Врата занимают слот Часов на колесе сил (свободного слота в игре нет). Пока у
    вас есть Часы, выберите слот один раз, чтобы взять Часы, и ещё раз, чтобы взять Врата.
  - Сквозь разлом не видно другую сторону (окно мерцало и снижало FPS, поэтому выключено).
  - Разлом может вести за пределы уровня; если провалились под карту, нажмите F, чтобы вернуться.
